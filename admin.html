Connect to GitHub

Paste your GitHub key once. It stays in this browser only, and it lets this page save changes and photos straight to the website.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → choose Ismile
  3. Permissions → Repository permissions → Contents → Read and write
  4. Generate the token and copy it (it starts with github_pat_)
