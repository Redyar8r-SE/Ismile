Connect to GitHub

Paste a GitHub key once. It stays in this browser and lets this page save changes and photos straight to the website.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → choose Ismile
  3. Permissions → Repository permissions → Contents → Read and write
  4. Generate the token and copy it (it starts with github_pat_)

Anyone who uses this computer could save to the site while the key is here. Press Sign out to remove it.
