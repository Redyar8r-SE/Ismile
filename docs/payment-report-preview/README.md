# Ticket and lunch payment report examples

The four records in this folder are fictitious examples showing cash, website,
older-receipt, and complimentary-ticket reporting. They contain no attendee data.

- [Registration and payment report PDF](Registration-Payment-Example.pdf)
- [Registration and payment CSV](Registration-Payment-Example.csv)
- [Lists print preview](Lists-Payment-Print-Example.html)
- [Payment breakdown screenshot](Payment-Breakdown-Example.png)
- [Example records](example-records.json)

The example conversion, **100 USD = 168,000 IQD**, is illustrative. It is not a
current exchange rate. Production reports use saved payment records; a missing
historical amount or rate is shown as `Not recorded`.
