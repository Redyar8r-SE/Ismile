2How we connect to Psoola: three connections

Our website and Psoola talk in only three ways. The code for all three lives in one file on our server, app/psoola.php, so if Psoola changes anything we fix it in one place.

A · Create a payment

Our server → Psoola

When the visitor presses Pay.

We send
amount, IQD, reference ISM26-…, visitor email/phone, return address
We get
Psoola payment ID + the payment page link
Secured by
our secret key (kept on the server)
B · Webhook

Psoola → our server

After the visitor pays (or fails).

They send
"payment X is paid / failed" to ismile.krd/api/webhook.php
We do
check the signature, write it in webhook_log, then run C
Secured by
signature or shared secret (ask Psoola, Q 4.1)
C · Check status

Our server → Psoola

After every webhook, and every 5 minutes for unpaid ones.

We ask
"what is the status of payment X?"
We get
paid or not, amount, currency
Then
only if paid and amount matches → ticket
Why C exists: a webhook message can be faked or lost. We never believe B alone. We ask Psoola ourselves (C) before making any ticket. If B never arrives, the 5-minute job still finds the payment through C.

3One payment, message by message

If the answer in 11 is "no" (wrong amount), no ticket is made and the payment shows in red in the admin.
