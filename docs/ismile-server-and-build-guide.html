Which server to buy, and how we build on it

For the owner. What kind of server, which features it must have and why nothing bigger is needed, then step by step how the backend gets built on it. Follows the backend plan of 27 Sep 2026.

1The answer in one line

Buy managed shared hosting with cPanel, about $5–20 per month, on a yearly plan, with servers in Europe. Not a VPS, not a dedicated server, not cloud (AWS / Google). Nobody on the team has to look after Linux, and it is more than strong enough.
Recommended

Managed hosting with cPanel

$5–20 / month
  • The hosting company updates the server and keeps it running
  • PHP, MySQL, SSL, email, backups, timed jobs: all ready
  • Everything is done with clicks in cPanel
  • If it breaks, their 24/7 support fixes it

VPS (your own virtual server)

$10–30 / month + work
  • More power and freedom
  • But someone must install, update and watch it every week
  • A missed security update is a real risk with payments and student photos
  • Only if you have that person. You do not, so: no.

Hostinger and SiteGround are good hosts but use their own panel, not cPanel. They would work too; this guide is written for cPanel. The .krd domain may not be sold by these companies. Buy it from a .krd registrar, then point it to the host (step 2 on page 3).

Before paying, ask the host's live chat these 3 questions: (1) Can cron jobs run every minute? (2) Can PHP make outgoing HTTPS calls to a payment company? (3) Are daily backups included, and for how many days? If any answer is "no", pick another host.

7Week 1: setting up the server, step by step

After you buy the domain and hosting. Who does what is shown on the right.

#StepWho
1Buy the hosting (yearly) and the domain ismile.krd for 2+ years, auto-renew on, in the organiser's name.You
2Point the domain to the host (change the "nameservers" at the domain seller to the ones the host gives).You, with the host's chat
3Turn on 2-step login for cPanel. Give the developer their own access, not your password.You
4In cPanel: set PHP to 8.3, switch on the extensions on page 2, upload limit 10 MB.Developer
5Turn on free SSL. Check that https://ismile.krd shows the padlock.Developer
6Create the subdomain test.ismile.krd and lock it with a password.Developer
7Connect GitHub with cPanel Git. Upload the current website to both.Developer
8Switch the admin to save on the server (server/admin.php). Test: edit and save a speaker.Developer + you
9Create the two databases and the private/ folder. Put the database passwords in secrets.php.Developer
10Create the email boxes info@, tickets@, sponsors@. Open the Brevo account and add its domain records.Developer + you
11Turn on daily backups; test one restore on the test site.Developer
12Old address (GitHub Pages) forwards to ismile.krd.Developer
13Send Psoola the account request and the questions document.You
Week 1 is done when: https://ismile.krd opens with the padlock, you can edit and save in the admin, test.ismile.krd exists, and the Psoola request is sent in writing.
